--- DESCRIPTION ---
Harbor taskset, 1 task: nl2repo-fail-closed-gate

Scope
NL2RepoBench-style clear document. Eight numbered behaviours, each with a
1:1 behaviour test. The agent receives the spec and an empty workspace and
must build a small Python 3.12 command-line tool from the document alone.

Scenario
Drawn from a real solo production lab: a publishing pipeline that refuses
to print a number it cannot source. Unknown number means print nothing and
exit non-zero. Silence is correct; a guessed number is not.

What is in the bundle
- task.toml — Harbor config, offline (allow_internet = false), 1 CPU, 2G
- instruction.md — the clear-document spec, eight numbered behaviours
- environment/Dockerfile — python:3.12-slim, pytest pinned, spec only, no golden source in the image
- tests/test.sh — pytest runner, writes reward to /logs/verifier/reward.txt
- tests/test_behavior.py — nine behaviour tests, 1:1 with the spec
- solution/ — golden implementation plus solve.sh

Discrimination
Golden solution: 9 of 9 tests pass. Empty workspace: 0 of 9 pass, so the
grader cannot award credit for nothing. Both verified locally before upload.

Deliberately excluded
No network. No database. No live CRM, chat, or credentials. No customer
data. No keys. The scenario is the subject; nothing production is in the box.

Not measured here
Scaffold rollouts (Qwen3.8 Max average, Opus 5 / Fable 5 max) are not
included. Those pass rates must be measured on your scaffold; they are not
estimated or asserted in this bundle.

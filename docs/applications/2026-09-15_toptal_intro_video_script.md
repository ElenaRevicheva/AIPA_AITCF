# Toptal intro video — script (4–7 min)

**For:** Toptal screening, "Record a video", 15 Sep 2026.
**Length:** about 700 words — roughly 5–6½ minutes at a calm pace. Under 4:00 is rejected; over
7:00 is outside the window.
**Style:** plain, professional English — short sentences, one idea each, easy to say.
**Facts checked against the PDF Toptal holds:** `13.09.26_EN_Resume_Elena_Revicheva_Toptal.pdf`.

## THE SCRIPT

### 1 · Hello *(~25 s)*

Hi, I'm Elena Revicheva. I live in Panama City.

I'm an applied AI engineer, and I work in an **AI-augmented** way. I want to say that clearly
from the start. I design and run real AI systems. I build them with AI coding tools — mainly
Claude Code and Cursor. I don't write the code by hand.

### 2 · My experience *(~1 min 15 s)*

How many years of experience do I have?

I have about **a year and a half** of full-time work building and running AI systems. I started
in 2025.

Here is how I work. First, I decide how the system should be built. Then I write down exactly
what each change must do. The AI tool writes the code. After that, I review it, test it, and
put it live.

I don't release anything I can't explain. And I check the logs to see what really happened.

Today I run **twelve live systems** on one Oracle Cloud server. They have been running for
eighteen months.

Before that, I worked for **seven years as Deputy CEO and Chief Legal Officer**. The company
built digital government services, and I was there from 2011 to 2018. I did not write code in
that job. I led big technology programs at board level. So I can talk easily with engineers,
and with the people who pay for the work.

### 3 · My most recent project *(~1 min 50 s)*

My most recent project is the **AI Visibility Audit API**. It is a public product at aideazz dot
x-y-z slash API.

In the past, businesses only cared about Google. Today, people also ask ChatGPT, Claude, Gemini
and Perplexity. If these AI assistants can't read a website, they won't recommend that
business.

My API checks any website. It scores **thirty-four signals** in four areas: AI crawler access,
structured data, content that AI can quote, and technical health. For each check, it shows
what it found and why it matters. When a check fails, it explains how to fix it.

I built the whole project: the design, the scoring rules, the API, and running it live on
Oracle Cloud.

People really use it. The server logs show more than **four hundred twenty audits**, **fourteen
thousand signals**, and **two hundred ten websites**. The median score is eighty-five.

One example of how I solve problems, from this week. Instagram started rejecting posts from
one of my automated systems. I found two causes. Some images were too tall for Instagram. And
one image link pointed to a code repository that had just become private.

First, I backed up every original image. Then I fixed both problems and checked that nothing
was lost. Posts are going out again. But I will only call it fixed after I see a real post with
the repaired images.

### 4 · My strongest technologies *(~1 min 20 s)*

Which technologies are my strongest?

My main languages are **Python** and **TypeScript**, with **Node.js** and **FastAPI**. For AI
agents, I use **LangGraph**. For memory, I use **PostgreSQL with pgvector**, so a bot remembers
each user. For business tools, I connect **HubSpot**, **Make**, **Resend** for email, and
**Playwright** to automate a browser. I run systems with **Docker** on **Oracle Cloud**.

I have used all of these for the last year and a half, in live systems.

What I do best is make AI systems **reliable**. If one AI provider fails, my system switches to
the next one. I use five: Anthropic, OpenAI, Google's Gemini, xAI's Grok, and Groq. When Groq
retired the models I used, nothing went down. I just changed a setting.

I also have **one hundred thirty automatic tests**, and they run in under a minute. And my
systems stop safely: if a file fails to load, my email system does not send the email.

### 5 · How to test me, and my availability *(~35 s)*

For the technical interview, I'd like to be tested the way I really work: a live task with AI
coding tools. You can watch me understand the task, guide the AI, review its code, and check
the result. That is the skill I bring to clients.

I'm looking for contract work, **twenty to thirty hours a week**. Every day, I can work from
nine a.m. to one p.m. New York time.

### 6 · Thank you *(~15 s)*

You can see my work and the live API on my portfolio: aideazz dot x-y-z slash portfolio.

Thank you for your time. I'd be happy to talk about how I can help your clients.

## Words to be ready to explain *(for you — not to read aloud)*

If a Toptal interviewer asks "what does that mean?", say it this simply.

| Word | Plain meaning |
|---|---|
| **AI-augmented** | I build software by guiding AI coding tools, and I check everything they produce. |
| **API** | A door other programs use to ask my system for an answer. |
| **Crawler** | A robot that reads websites — like the ones ChatGPT and Google send. |
| **Structured data** | Hidden labels on a web page that tell a machine what is what: this is a price, this is an address. |
| **Logs** | The system's diary of what actually happened. |
| **LangGraph** | A tool for building an AI agent that works step by step and remembers where it is. |
| **PostgreSQL / pgvector** | A database, plus an add-on that finds information by meaning, not by exact words. |
| **Fallback** | A backup plan: if one AI provider fails, use the next. |
| **Automatic tests** | Small programs that check the system still behaves correctly after a change. |
| **Stop safely** | When something is wrong, the system stops instead of doing the wrong thing. |
| **Docker** | A box that packs a program with everything it needs, so it runs the same everywhere. |
| **Median 85** | Half the websites scored above 85, half below. |

## Delivery notes

- **Section titles are for you** — don't read them.
- **Pause after each question** before you answer. Pauses sound confident.
- **Say numbers slowly:** "four hundred twenty", "fourteen thousand", "two hundred ten".
- **Grok and Groq sound alike** — say "xAI's Grok", then a clear "and Groq".
- **Timing:** under 4:30 → speak slower in sections 3 and 4. Over 6:45 → skip the Instagram
  example (the last two paragraphs of section 3).
- **Look at the camera** on the first and last sentence of each section.

## Do not say on camera

- Any number not on the Toptal PDF (no application counts, no DataVendor price, no "137 tests").
- "Senior software engineer", or anything that suggests you write production code by hand.
- That you can pass a timed coding test without AI tools.
- That the Instagram fix is proven — it isn't yet, and saying so is the stronger answer.
- "Every day" about a single tool.
- The films / YouTube promo work (portfolio only, per the 13 Sep review).

05 · Ownership under failure

What I do when it breaks — and what it’s called.

Silent failure

An integration that never said it was broken

Found

Trial sign-ups had never reached the CRM since launch — while the sender’s log looked healthy.

Did

Audited from the receiving end, root-caused, fixed, and backfilled all 28 lost users.

Vacuous guard

A spending cap that could never fire

Found

The pre-render budget guard read a price field the vendor never sends — so every price passed.

Did

Fixed the guard against the vendor’s real response and published the postmortem.

Evaluation gate

The more complex model lost

Found

A RAG upgrade to my screening judge scored lower on an evaluation set built from my own real decisions.

Did

Shipped it switched off. Accuracy beats sophistication.

Graceful degradation

A provider retired its models. Nothing went down.

Found

A vendor deprecated the models my agents used.

Did

The five-provider fallback chain kept the fleet serving — a config change, not an outage.
